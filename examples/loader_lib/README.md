为了方便文档的叙述，我们先约定一些常用的名称。

* `Kernel[代码/空间]`: 内核相关代码、内核被加载到的地址空间。
（尽管我们是一个 `Unikernel`，但我依然在此将内核相关的代码称呼为 `Kernel`）

* `App[区/代码/空间]`: 应用相关的内存区域、内核相关代码、内核内核空间
